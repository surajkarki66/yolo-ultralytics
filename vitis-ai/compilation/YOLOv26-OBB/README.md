# YOLOv26-OBB / YOLOv11-OBB model

Place the quantized **OBB** (oriented bounding box) XIR model here (e.g. `OBBModel_int.xmodel`) before running `run_compile.sh` or `vai_c_xir` from the parent `compilation/` directory. This folder is used for **YOLOv26-OBB and YOLOv11-OBB** exports. See `../README.md` for the compilation procedure.
