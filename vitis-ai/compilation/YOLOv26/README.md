# YOLOv26 / YOLOv11 detection model

Place the quantized **detection** XIR model here (e.g. `DetectionModel_int.xmodel`) before running `run_compile.sh` or `vai_c_xir` from the parent `compilation/` directory. This folder is used for **YOLOv26 and YOLOv11** detection exports. See `../README.md` for the compilation procedure.
